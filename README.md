# Ты меня простишь?

Открой сайт так, чтобы работали уведомления в Telegram:

```bash
cd romantic-site
python3 server.py
```

Потом открой адрес сервера в браузере.

**Подключить бота (это делаешь ты, не она):**
1. В Telegram найди @BotFather, скопируй токен.
2. Открой своего бота и нажми Start.
3. На сайте **зажми большое сердце 💗** примерно на 2 секунды (или нажми его 5 раз подряд).
4. Вставь токен → «Найти мой чат» → «Сохранить и проверить».

Тебе должно прийти: `Проверка: уведомления работают ❤️`.

Токен лежит в `telegram.json` на сервере, в страницу он не попадает.

Если запустить обычный `python3 -m http.server` — сайт откроется, но Telegram не подключится.

Текст и имена — в начале `script.js` (`CONFIG`).
